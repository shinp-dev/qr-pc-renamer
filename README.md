# 実習室PC管理ツール

## 概要

実習室や教室のWindows PC名を管理するためのRustモノレポです。

- **PC名変更ツール**：QRコードを読み取ってWindowsのPC名を変更します。
- **PC名QRコード一括作成ツール**：PC名一覧からQRコード画像を一括生成します。

両ツールは`crates/pc-name`のPC名検証ルールを共有しています。

## リポジトリ構成

```text
.
├─ src/                         PC名変更ツール
├─ apps/qr-batch-generator/     QRコード一括作成ツール
├─ crates/pc-name/              共通のPC名検証
└─ landing-page/                GitHub Pages用LP
```

## ビルド

```powershell
cargo build --workspace --release
```

次の実行ファイルが`target\release`に作成されます。

- `pc_renamer.exe`
- `qr-batch-generator.exe`

## PC名変更ツールの使い方

**【重要】** 必ず「管理者権限のあるユーザー」でWindowsにログインした状態で実行してください。
（実行時に自動的に権限昇格の確認が出ますが、管理者権限がないユーザーだとパスワードを求められるか失敗する場合があります）

1. `run_renamer_qr.bat` をダブルクリックして実行します。
2. 「このアプリがデバイスに変更を加えることを許可しますか？」という画面（ユーザー アカウント制御）が出たら、「はい」をクリックします。
3. 黒いコマンドプロンプト画面と一緒に、QRコード読み取り用のカメラウィンドウが起動します。

### QRコードを使う場合

- カメラにPC名が書かれたQRコードをかざしてください。
- 読み取りに成功すると画面にPC名が表示され、変更してよいか確認されます。

### 読み取り内容を修正する場合

- QRコードを読み取れなかった場合や、読み取ったPC名を修正したい場合は手入力へ切り替えられます。
- 「新しいPC名を入力してください」と表示されるので、キーボードから直接入力してEnterを押してください。

### 完了後

1. 変更が完了すると、「✔ コンピュータ名の変更に成功しました」と表示されます。
2. 何かキーを押して画面を閉じます。
3. **※重要※ 変更したPC名を完全に反映させるために、PCを再起動してください。**

### PC名のルール

- 15文字以内の半角英数字とハイフンを使用してください。
- 英字を1文字以上含めてください。
- ハイフンは先頭・末尾には使用できません。

## その他・注意点

- PC名を変更した履歴は、「rename.log」というファイルとして自動で保存・追記されていきます。
- 実行時に「現在の PC 名」と「新しい PC 名」が同じ場合は、変更処理を行わずに終了します。
